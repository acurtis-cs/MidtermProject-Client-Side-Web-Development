# CS300 Midterm Project

This project was created for CS300: Client-Side Web Development at Northeastern Illinois University.

The goal of the project is to recreate a provided webpage design using the HTML and CSS skills covered in class up to this point.

## Project Goals

- Recreate the provided webpage as closely as possible
- Apply HTML page structure
- Apply CSS styling and formatting
- Use floating and positioning
- Work with colors and transparency
- form input
- Use provided images and fonts
- Maintain proper file organization and relative paths

## Technologies Used

- HTML
- CSS

## Project Structure

The project contains:

- HTML files for the webpage structure
- CSS files for styling
- Image files used throughout the page
- Font files used for the design

## Repository Use

This repository is being used to keep the project synchronized while I work on it from two different computers and locations.
